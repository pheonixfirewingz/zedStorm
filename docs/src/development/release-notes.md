# Release Notes

ZedStorm does not include the upstream release-note collection or publishing
workflows. Record changes manually when preparing a release.

Pull request descriptions use a final `Release Notes:` section with one bullet:
`Added`, `Fixed`, or `Improved` for user-facing changes, or `N/A` for changes
without a user-facing effect. Changes to GPUI use the `[GPUI]` prefix.

```markdown
Release Notes:

- Fixed a crash when opening a project.
```
