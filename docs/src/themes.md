# Themes

ZedStorm uses one fixed colour theme: **Islands Dark**. The editor, terminal, and Markdown preview use the same application palette.

The palette is defined in `assets/themes/islands/islands.json` and compiled into the application. Edit that file and rebuild ZedStorm to change its colours or syntax styles. The adjacent `LICENSE` records the palette's attribution.

Theme selection, light/dark mode switching, local theme files, extension colour themes, `theme_overrides`, `experimental.theme_overrides`, and `markdown_preview.theme` do not change the palette. Legacy settings remain readable for compatibility.

Fonts, font sizes, UI density, and [file icon themes](./icon-themes.md) remain configurable.
